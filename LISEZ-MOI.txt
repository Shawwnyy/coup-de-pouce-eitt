COUP DE POUCE BY EITT

>>> DOUBLE-CLIQUEZ SUR :  Coup-de-Pouce.html  <<<

- Pas d'inscription, pas de mot de passe, rien à installer.
- Cliquez sur "Commencer" : un profil avec un numéro au hasard (ex. User#4827) est gardé dans votre navigateur.
- On retrouve quelqu'un par son nom (ex. "Léo.G") ou par son numéro.
- Vous pouvez en créer d'autres, changer le nom, supprimer un profil.
- Images, GIF, vidéos et liens fonctionnent (gardés dans ce navigateur).

Quelqu'un utilise l'appli sur un autre appareil ? Sans serveur on ne le voit pas tout seul :
menu en bas de page "Autre appareil (code)" -> on s'echange un code, puis des fichiers de messages.
Votre code de partage (CDP1...) est aussi affiche dans votre profil, avec un bouton "Copier mon code".
MODE EN LIGNE (beta) : case cochee par defaut a la creation du profil (decochable) ; les anciens profils recoivent une seule pop-up pour l'activer. Interrupteur "Passer en ligne" sous l'en-tete. CODE COURT : donnez votre User# ; l'autre le tape dans la recherche, une pop-up propose d'envoyer la demande. En ligne, on ajoute quelqu'un en tapant son User# dans la recherche ; la demande arrive en quelques secondes et on s'ecrit en texte chiffre (via un relais public, par defaut ntfy.sh). Images/videos : fichier d'echange. Pas de moderation. IMPORTANT : les DEUX personnes doivent cliquer "Passer en ligne". Un contact ajoute par code seulement ne recoit rien tout seul : un message "Pas envoye" s'affiche et un bouton propose de passer en ligne et d'envoyer la demande. Voir README pour les limites.

Important : tout reste sur CET ordinateur, dans CE navigateur. Ce n'est pas un chat entre
plusieurs appareils. Les conversations se font entre les profils créés ici
(ouvrez 2 onglets, un par profil).

Ne double-cliquez PAS sur index.html (c'est le fichier source : page blanche).
Le détail complet est dans README.md (section 00).

MODIFIER / SUPPRIMER : menu "..." d'un de vos messages. EN TRAIN D'ECRIRE : affiche chez l'autre pendant que vous tapez (coupable dans Parametres > Compte). PENSEE DE LA MINUTE : change chaque minute, a droite sur ordinateur, en bas sur telephone (masquable).

SALON GENERAL : page "Salon" (barre du haut). Un salon pour tous les profils. Par defaut il reste sur CET appareil (tous les profils du navigateur). En option : "Rejoindre le salon en ligne" = salon PUBLIC via le relais ntfy, NON chiffre, SANS moderation : tout le monde peut lire et ecrire, les noms et numeros ne sont pas verifies (regardez l'empreinte #xxxxxx), texte seulement (300 caracteres), liens non cliquables, un message toutes les 2 s, "Masquer" cache une personne seulement pour vous. Ne partagez ni mot de passe, ni adresse, ni telephone. Teste avec un faux relais ; pas avec le vrai ntfy.sh. Details : README.
